## 📖 概要

AquaBeacon は、海のように広く自由な発想を大切にしながら、灯台のように進むべき方向を示すプロジェクトです。水上の親機と水中の子機をつなぎ、音で距離を、光で方向を捉える水中位置推定・マッピングシステムを開発しています。
