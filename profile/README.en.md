## 📖 About

AquaBeacon values open, ocean-wide thinking while guiding the way forward like a lighthouse. We are developing an open-source system for underwater positioning and mapping, using sound to measure distance and light to sense direction between a surface unit and an underwater unit.

**COMING SOON ...**

Software, hardware designs, validation documentation, and guides are being prepared for release.
